# DictionaryPC

Java code to generate dictionaries for QuickDic Android app
(see [Dictionary](https://github.com/rdoeffinger/Dictionary) repo).
Fork of project that used to be hosted at code.google.com/p/quickdic-dictionary


## Dependencies

Libraries needed by `compile.sh`:

- Debian 13: `junit4 libcommons-text-java libicu4j-java`
